# E 计量与统计方法学工作流

## 速读
方法解决的问题 → 核心概念 → 作者指出的问题或提出的改进 → 关键条件 → 实际使用启示。区分新估计量/推断理论、方法比较、方法论辨析等子类型；不强求都有新定理或数据集。

## 方法层精读
- 明确研究对象：估计对象、估计量、识别条件、统计性质或研究操作。区分“可识别”与“能估计”、统计关联与因果解释。
- 可读公式解释变量、参数、条件及用途；不要将教学回归式误写为作者实际运行的回归。
- 方法论辨析用“常见做法—问题来源—成立/失效条件—作者建议—适用边界”组织。分析中介、调节时区分作用渠道、效应异质性和识别论证；记录本文用词定义，不把作者术语选择当所有领域统一标准。
- 有定理时说明假设、结论和证明思路，逐步证明仅按用户指定展开；有模拟则核对数据生成过程、比较方法、评价指标和结论范围；有应用则区分演示与独立经验贡献。
- 作者对操作的建议属于作者陈述，不与AI为用户另提的研究建议混淆。指出建议依赖的研究目标和条件，不把一篇方法讨论推广为无例外禁令。
- 默认解释方法如何使用及何时不适用；代码仅用户要求时提供，并区分演示代码与复现代码，不声称未运行代码已验证。
