# 分类规则

分类的目的在于选择解释框架，不是评价论文质量。主类型决定骨架，辅助模块覆盖真实存在的内容；不因主类型排除公式、数据或史料。

| 主类型 | 判定问题 | 避免误判 |
|---|---|---|
| A 实证 | 主要新知识是否来自对观测/实验数据的分析？ | 不将所有实证都当准实验；模型化分解也是实证 |
| B 数理理论 | 主要贡献是否为经济主体行为、均衡或机制的形式化模型与命题？ | 有公式不足以判B；不要求必须有连续优化FOC |
| C 制度与思想史/非形式化理论 | 是否主要通过制度事实、概念和逻辑链解释经济现象，或通过史料研究思想演变？ | 明确子类型；制度理论不自动是思想史；引用他人回归不等于自己做实证 |
| D 综述 | 主要任务是否组织、比较、综合既有研究？ | 引用多不等于综述；综述可以包含数学说明或定量综合 |
| E 方法学 | 主要对象是否为识别、估计、推断方法或研究实践的正确使用？ | 公式和定理不自动判B；用于演示方法的应用不自动判A |

B与E的区别在于主要解释经济机制还是研究方法；D与E的区别在于主要综合既有研究还是提出方法论辨析。混合时选主要贡献，说明辅助模块；证据不足则标“暂定”并说明需要核查什么，不编可信度百分比，不阻塞可完成的速读。

首答一句定位包含：主类型、必要的子类型/辅助模块、判断依据及对应章节。精读发现新证据可修正，并简述原因。用户的类型标签可作线索；与原文不符时解释调整。
