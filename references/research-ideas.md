# 按需研究启发

仅用户提出选题、场景迁移、研究设计改进等需求时启用。可以在报告末尾提供入口，但不默认生成整套建议。先利用已有背景；缺少关键信息时只问影响可行性的条件，如可用数据、期限、方法基础和研究兴趣。

每项建议标AI建议，包含：本文依据与动机 → 具体问题 → 所需数据及可获取状态 → 候选识别/理论路径 → 困难及失败条件 → 最小可行验证步骤。区分作者明确指出的限制、AI发现的未回答问题和经外部检索确认的空白。

场景迁移必须解释原机制为何可能适用、哪些制度条件可能不同；不机械套中国微观调查、数字或绿色经济。不声称某数据库一定包含所需字段或可免费获得。

方法升级须针对已识别的设计问题，说明新方法需要的假设、数据与代价，以及不能解决的限制。新估计器、RDD或机器学习不能凭空创造识别；没有充分理由时可建议保留原方法并改善数据或论证。

建议数量依用户要求，默认少量可行动方向；无充分信息则给条件性方案，不承诺显著结果、发表或毕业可行性。需要最新文献、数据可用性或软件用法时，使用实际可用的核验能力；不能核验则明确保留状态。
