# EconReader-Pro｜因果识别型实证论文分析模板

> 用途：供 AI 阅读因果推断论文时作为输出结构与分析规则。示范案例：Song, Wu & Zheng (2024), *An Unintentional Consequence of Taxation: Tax Cuts and Vertical Pay Dispersion*。本模板不意味着所有因果论文都采用 DID；先识别方法，再启用相应字段。

## 一、执行规则（AI 必须遵守）

1. **先判断方法**：区分二元 DID、连续处理 DID、分期处理 DID、事件研究、IV/2SLS、RDD、合成控制、分布分解、普通面板回归等。不要因为出现 `Post × X` 就自动判定为标准二元 DID。
2. **事实与评价分离**：每个重要判断标注 `[作者报告]`、`[AI解释]`、`[AI评价]` 或 `[待核验]`。
3. **证据定位**：尽量为每个变量定义、估计式、结果数字、检验结论附论文页码、章节、方程或表图编号。不能定位时明确写“待核验”，禁止编造。
4. **准确转录**：核对变量符号、上下标、基准期、变量单位、系数和显著性。PDF 公式解析不清时不要猜测。
5. **区分识别与检验**：平行趋势、无预期效应、共同冲击、外生性、排除限制等是需要论证的条件；事前系数不显著、安慰剂不显著都不能“证明”假设成立。
6. **区分机制证据与机制证明**：分组回归、交互项、可解释/不可解释薪酬差距通常提供与某机制一致的证据，不自动排除其他机制。
7. **区分估计对象**：ATE、ATT、每单位处理强度效应、组间预测差异、LATE、IV 局部效应不可以混称。
8. **不机械填表**：未使用的研究方法标注“不适用”；缺少的信息标注“未报告/当前材料无法核验”。

## 二、可复用输出结构（用于分析任意新论文）

### 0. 文献档案与方法路由
- 标题、作者、年份、期刊、DOI：
- 研究领域、样本、研究期间：
- **核心研究问题**：
- **方法判定**：主要识别策略、辅助方法、经济后果识别策略分别是什么？
- **判定依据**：对应的原文方法名称、估计式、章节。
- **一句话结论**（限定为作者报告的结论）：

### 1. 因果问题与识别对象
- 目标因果关系：`处理/政策 → 结果变量`。
- 反事实问题：若未受政策影响，同一研究对象的结果本应如何变化？
- 研究单位、观测频率、样本限制：
- 政策发生时间与观察窗口：
- 目标参数（estimand）：系数对应“每单位强度差异的政策后相对变化”还是某种平均处理效应？
- 如果存在第二条因果链，单独列出其内生解释变量、结果变量和识别策略。

### 2. 理论机制与可检验预期
| 机制 | 理论路径 | 可观测代理变量 | 预期方向 | 实际检验 | 结论强度 |
|---|---|---|---|---|---|
| 机制 A | | | | | |
| 竞争机制 B | | | | | |

### 3. 数据、样本与变量字典
- 数据来源、时间范围、样本筛选、删除年份及理由：
- 因变量（精确定义、公式、单位、对数变换）：
- 处理变量（构造公式、正负号、是否使用政策前数据）：
- `Post` 的定义与政策当年如何处理：
- 控制变量（是否滞后及其理由）：
- 固定效应、标准误聚类层级、样本量：
- 数据泄漏/事后变量风险：处理强度是否由政策后行为或结果反向决定？

### 4. 核心估计方程与逐项解释
用论文原式准确转录，解释：
- 因变量与处理交互项；
- 系数的数学含义、经济含义、单位；
- 个体/时间固定效应吸收什么；
- 控制变量与误差项；
- 为什么这是一种 DID 或其他方法；
- 哪些比较提供识别（跨企业的处理强度差异 × 政策前后变化）。

**若为连续处理 DID：**
- 处理强度是否为连续值？是否存在真正未受影响的对照组？
- 基准系数是“每单位强度的相对变化斜率”，而非自动等于 ATT。
- 用 `β × (强度高组均值 − 强度低组均值)` 计算两组预测差异时，解释所用强度差和因变量单位。
- 关注连续处理强度的条件平行趋势、潜在非线性与异质性问题。

### 5. 因果识别假设与威胁
| 假设/威胁 | 为什么重要 | 作者证据 | 证据局限 | AI 评价 |
|---|---|---|---|---|
| 条件平行趋势 | | | | |
| 无预期效应 | | | | |
| 政策同期其他冲击 | | | | |
| 处理强度内生性 | | | | |
| 样本选择/退出 | | | | |
| 误差相关与聚类 | | | | |

### 6. 结果与经济量级
| 模型/表 | 核心系数 | 标准误或置信区间 | 显著性 | 经济解释 | 证据位置 |
|---|---:|---|---|---|---|
- 明确区分百分比、百分点、对数点及近似百分比。
- 若 `Y = ln(薪酬比)`，`βΔx` 为对数差，百分比变化的精确换算是 `100 × [exp(βΔx) − 1]%`，小变动可用 `100 × βΔx%` 近似。
- 不能将“显著”直接等同于“经济意义大”。

### 7. 动态检验、稳健性与安慰剂
逐项列出：检验目标 → 具体操作 → 报告结果 → 能支持什么 → 不能证明什么。
- 事件研究/动态 DID：基准期、事前联合检验、事后效应持续性。
- 安慰剂：虚假政策时间、虚假处理强度、是否存在机械相关。
- 替代处理定义、替代估计器、样本调整、结果变量替换。
- Fuzzy DID/Wald-DID：写明工具变量或鼓励变量、实际处理、compliance、分子分母及 LATE 解释；不可仅凭“分组不清晰”推断其含义。

### 8. 机制检验
- 每个机制使用什么指标、如何分组或构造？
- 是否使用政策前测量的机制代理变量？
- 组间系数差异是否正式检验？
- 竞争机制未显著 ≠ 已证明该机制不存在。
- “无法解释部分”是相对于特定模型未解释，不自动等于高管寻租的直接测量。

### 9. 经济后果：独立的第二个因果问题（如适用）
- 第二个结果变量是什么？
- 内生解释变量是什么？
- 作者是否使用 IV/2SLS 或其他策略？
- **第一阶段**：工具变量如何预测内生解释变量？相关性证据？
- **第二阶段**：被工具化的变量如何影响结果？
- **排除限制**：工具变量是否可能通过其他渠道直接影响结果？
- **局部解释**：在什么条件下才能解释为因果效应？
- 若论文仅提供“两阶段回归”表述，必须检查实际方程和估计程序，不擅自断定标准 2SLS。

### 10. 综合评价与研究启发
- 作者结论（有证据定位）：
- 识别优势：
- 最关键的剩余威胁（优先排序）：
- 哪些结论是相关性、哪些具有条件性因果解释？
- 可复制/可拓展的研究设计：
- 需要补充核验的公式、附录、数据或代码：

### 11. 学习问答区（可选）
对用户笔记中的每个疑问，采用：`问题 → 直接回答 → 直观例子/必要公式 → 对应原文位置 → 常见误区`。不要把未经核验的旧 AI 回答当作事实。

## 三、已填充示范案例：Song、Wu、Zheng（2024）

### 0. 方法识别
- **论文**：*An Unintentional Consequence of Taxation: Tax Cuts and Vertical Pay Dispersion*，Journal of Business Finance & Accounting（2024）。
- **研究问题一**：2009 年中国增值税改革造成的减税强度差异，是否改变企业内部高管与普通员工的垂直薪酬差距？
- **主方法**：企业面板固定效应 + `Post_t × ΔVAT_i` 的**连续处理强度 DID**。
- **辅助方法**：动态事件研究、虚假政策年份安慰剂、替代处理划分、Fuzzy DID / Wald-DID、机制异质性分析。
- **研究问题二**：改革引致的薪酬差距扩大是否损害企业绩效？作者使用两阶段方法进一步分析，具体 IV 条件须单独评价。
- **原文定位线索**：第 4 节模型（1）（2）；第 5.2—5.9 节；表 2—11。

### 1. 数据与研究设计
- **数据**：中国上市制造业企业，CSMAR，2005—2018 年；排除改革年份 2009 年，并要求企业在改革前后均有观测。`[作者报告]`
- **因变量**：高管/CEO 与普通员工平均薪酬之比的自然对数；另用最高薪三位高管及全体高管口径替换。`[作者报告]`
- **处理强度**：`ΔVAT_i`，表征改革带来的企业层面增值税税负变化/减税程度；精确构造式及正负号需与原文方程（2）核对。`[待核验]`
- **政策后虚拟变量**：`Post_t`；2009 年排除，改革后年份作为政策后期。`[作者报告]`
- **控制**：滞后一期的企业规模、杠杆、ROA、现金流、增长、费用率、股权结构、产权性质、地区经济指标等。`[作者报告]`
- **固定效应**：企业与年份。标准误聚类层级需核对论文原表注。`[作者报告/待核验]`

### 2. 主估计式

`Dispersion_it = α₀ + α₁(Post_t × ΔVAT_i) + φX_{i,t−1} + δ_i + λ_t + ε_it`

- `δ_i`：吸收不随时间变化的企业特征；`λ_t`：吸收共同年份冲击。
- `α₁`：政策后，**减税强度每增加一个单位**对应的垂直薪酬差距相对变化，不自动等于二元处理组 ATT。`[AI解释]`
- 可以为直观呈现把企业按减税强度高低分组，但这种展示**不等于**主回归使用二元处理变量。`[AI解释]`
- 条件平行趋势的含义：在没有改革的反事实情形下，不同预定减税强度企业的薪酬差距趋势不存在与强度系统相关的差异（在模型控制条件下）。`[AI解释]`

### 3. 系数经济量级演示
- 笔记转录主系数 `0.756`，高减税组与低减税组平均强度差为 `0.024 − (−0.028) = 0.052`。
- 对数结果变量的预测差：`0.756 × 0.052 = 0.039312` 对数点。
- 近似百分比：`3.9312%`；精确百分比：`100 × [exp(0.039312) − 1] ≈ 4.01%`。
- 论文使用约 `3.93%` 的线性近似；这不是“所有企业平均增加 3.93%”，而是**两组代表性减税强度差对应的预测效应差**。`[AI解释]`
- 原文定位线索：第 5.2 节、表 2 附近。具体系数所属列及标准误待核验。

### 4. 机制证据
- **管理权力/租金提取渠道**：用政策前（2005—2008 年）管理权力指标分组，比较高、低权力组的改革效应，并以置换检验比较系数差异。`[作者报告]`
- **绩效薪酬渠道**：按政策前 PPS 分组，未发现支持该机制的对应证据。`[作者报告]`
- **EPR/UPR 分解**：将可由模型解释的薪酬比率与无法解释的薪酬比率区分；改革与 UPR 增加相关，而 EPR 的结果不显著。`[作者报告]`
- **评价边界**：UPR 是相对于预测模型的“未解释部分”，不应直接等同于被观察到的违法侵占或寻租行为；机制检验提供一致性证据而非唯一机制证明。`[AI评价]`
- 原文定位线索：第 5.3—5.6 节，表 3—6。

### 5. 识别检验与局限
- **动态检验**：笔记记载改革前 2005—2008 年交互项不显著、2011—2015 年显著为正；应写作“未检测到显著的改革前差异趋势”，而不是“证明平行趋势成立”。`[作者报告 + AI评价]`
- **安慰剂**：虚设 2007、2008 年为改革年份，交互项不显著；可增强设计可信度，但不能排除所有同期冲击。`[作者报告 + AI评价]`
- **Fuzzy DID / Wald-DID**：属于不同于基准连续处理 DID 的稳健性策略；需核对作者定义的工具变量、实际处理及 LATE 识别条件。`[待核验]`
- **关键威胁**：企业原有资本结构/固定资产构成与减税强度相关，也可能关联未来薪酬变化；改革可能直接影响企业绩效，给后续工具变量排除限制带来挑战。`[AI评价]`
- 原文定位线索：第 5.7—5.8 节，表 8—10。

### 6. 经济后果：第二个识别任务
- **内生解释变量**：垂直薪酬差距；**结果变量**：后续企业业绩变化（如 ROA 和市账率变化）。`[作者报告]`
- **思路**：用改革相关的薪酬差距预测成分分析其与未来绩效的关系。`[作者报告]`
- **核心限制**：税改可能通过税后现金流、投资和经营活动等途径**直接**影响绩效，而不只通过薪酬差距；因此不能因为政策是全国统一实施，就断言 IV 的排除限制成立。`[AI评价]`
- **方法提醒**：需要核对原文第 5.9 节实际估计方程、工具变量定义、第一阶段强度及标准误计算，才能判断其两阶段估计是否具有标准 2SLS 的解释。`[待核验]`

### 7. 对原始学习笔记的必要纠错
1. **固定效应**：企业 FE 与年份 FE 不是因为“它们一定固定不变”而选用，而是用以吸收企业不变特征及共同时间冲击；不能吸收随时间变化的遗漏因素。
2. **滞后控制变量**：滞后一期有助于减少部分同时性疑虑，但不能保证消除反向因果或所有内生性。
3. **分位数解释**：第 10 百分位数是样本经验分布的位置，无需假设正态分布。
4. **横截面检验**：此文语境下主要是**按企业特征分组的异质性/机制检验**，不是把面板数据误认为单期横截面。
5. **动态 DID**：政策前系数不显著不是平行趋势的数学证明；应关注置信区间和联合检验。
6. **安慰剂**：虚假年份回归不显著是支持性证据，不证明其他未观测因素都不存在。
7. **Fuzzy DID**：不能仅定义为“给企业不同权重”；需依照实际处理遵从、工具变量和 Wald 比值定义。
8. **置换检验**：检验组间估计系数差异的显著性，不会自动控制内生性。
9. **两阶段回归**：不能笼统说“把内生性转变成外生”；因果解释依赖相关性、排除限制等条件。
10. **政策强度**：基准 `Post × ΔVAT` 是连续强度设计，不应简单把高组称作受处理、低组称作完全未处理。

### 8. 此案例用于 AI 测试的检查点
- 能否把连续强度 DID 与标准二元 DID 区分？
- 能否解释 `0.756 × 0.052` 的经济含义及对数换算？
- 能否区分政策对薪酬差距的效应与薪酬差距对绩效的效应？
- 能否指出平行趋势检验与 IV 排除限制的证据边界？
- 能否在缺少原文精确公式或表注时标记待核验，而不是补造信息？
