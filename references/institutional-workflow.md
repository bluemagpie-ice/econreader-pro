# C 制度、思想史与非形式化理论工作流

## 速读
核心问题及概念 → 制度/时代背景 → 作者的解释链 → 支持论据 → 贡献与适用边界。注明子类型：制度分析、非形式化理论或思想史等。

## 论证层精读
- 概念的定义、适用对象与时代范围；不要把现代含义直接套入历史文本。
- 将论证拆为“前提—激励/行为逻辑—中间推论—最终主张”，定位关键段落；作者论断与AI重构分开。
- 列出制度事实、史料、案例、描述统计和引用的他人研究，各自支持哪个环节。区分本文原始证据与二手转述，未读原研究时不声称复核。
- 思想史侧重文本版本、概念变迁、历史语境和解释分歧；制度分析侧重规则、执行、激励、适用条件及成本。只输出相关内容。
- 作者明确提出的政策建议单列；规范性主张不当作经验事实，解释性框架不自动是已识别的因果关系。
- 默认仅简短评价主要证据与边界。用户要求批判性研读时才系统比较竞争解释、逻辑跳跃、反例与证据代表性。

无正式模型不意味着无理论；引用锦标赛、委托代理等理论时解释其在本文的作用，不自行补写原文不存在的模型。
