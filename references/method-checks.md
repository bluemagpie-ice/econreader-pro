# 方法专项

只启用论文实际使用的设计。这是阅读检查表，不要求论文必须实施所有检验。

| 设计 | 核对重点 | 边界 |
|---|---|---|
| 回归/面板固定效应 | 变异、控制、固定效应、标准误、时变遗漏因素 | 无额外论证保留条件相关解释 |
| 分布分解 | 参数、映射假设、约束模型、拟合与不确定性 | 统计分解不自动识别因果机制 |
| 二元DID | 处理对照、时点、平行趋势、预期、同期冲击、溢出和聚类 | 事前不显著不证明平行趋势 |
| 连续强度DID | 强度构造及符号、时间、真实未处理对照、函数形式与异质性 | 交互系数不自动为ATT，结合尺度和假设解释 |
| 分期DID | 批次、对照构成、异质效应、估计器、窗口 | 注意传统双向固定效应的比较问题 |
| 事件研究 | 基准期、联合检验、置信区间与支持样本 | 动态图不建立外生性 |
| IV/2SLS | 工具、内生变量、第一阶段、弱工具、排除限制、适用时单调性和局部解释 | 两次回归未必是2SLS；可能存在直接渠道 |
| RDD | running variable、阈值、sharp/fuzzy、带宽、操纵与连续性 | 通常是局部识别 |
| 随机试验 | 分配单位、依从、流失、溢出、推断单位、ITT | 随机分配不消除全部实施与外推问题 |
| 合成控制 | 供体、干预前拟合、污染、安慰剂与推断 | 好拟合不保证无同期特有冲击 |
| 结构估计 | 行为假设、识别、校准与估计、拟合及反事实 | 结论依赖模型假设 |

未覆盖方法依据原文建立参数—假设—证据链，不强行分类。多个因果问题分别核对，主分析识别不能自动传递到后续经济后果分析。
