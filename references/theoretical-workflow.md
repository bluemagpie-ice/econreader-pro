# B 数理理论工作流

## 速读
问题 → 相对基准模型改变了什么 → 核心设定 → 主要命题及直觉 → 成立条件与贡献。事实附原文位置。不默认输出数据、回归或稳健性章节。

## 模型层精读
1. 主体、时序、行动空间、信息结构、状态与不确定性、偏好及技术；区分外生参数与内生选择。
2. 写出可靠可读的目标函数、可行集合及关键约束，解释符号、激励相容、参与条件或均衡概念。FOC、市场出清只在适用时分析；离散选择、线性规划、博弈与契约不能硬套微分最优化。
3. 核心命题按“假设—结论—直觉—边界—原文位置”组织；说明命题依赖哪些先前结果，区分定理、例证和作者推测。默认给证明思路，不逐行展开全部证明。
4. 有比较静态、福利或反事实时解释其模型内含义；没有则省略。理论结论不能当已验证的经验事实。
5. 有校准/模拟时分析参数来源、校准与估计区别、数值实验设计、敏感性及其作用；脉冲响应只在实际存在时读。无模拟则省略或注明，不将“无模拟”误作模型边界；边界来自假设和命题范围。
6. 有实证应用则启用A辅助模块，区分理论预测和经验检验。

## 指定命题后的推导
确认命题与证明是否可读、附录是否齐全。解释所需定义、每一步的依据和经济直觉；AI补充推导单独标注，不冒充作者原证明。证明缺页或公式不清则指出断点，不能声称已验证完整证明。需要时用明确标为教学的简化例子。
