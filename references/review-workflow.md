# D 文献综述工作流

## 速读
主题与覆盖范围 → 作者的分类框架 → 主要观点与分歧 → 综合结论 → 覆盖限制。根据原文可以按主题、方法、时间或流派组织，不强制造出学派争鸣与演进史。

## 综合层精读
1. 记录综述问题、地域/时期、文献范围；检索库、检索式、纳入排除和质量评价仅在实际报告时提取。无系统检索说明不称系统综述；无法确认覆盖范围时不编起止年份。
2. 整理“主题/观点—代表研究（依综述所述）—依据—综述作者评价—原文定位”。明确被引研究的观点、综述作者综合和AI归纳三层归属。
3. 未获取被引原文时写“该综述转述某研究认为……”，不能宣称已核对被引论文的数据、结论或引文。参考条目不得凭记忆补齐。
4. 共识限于综述覆盖材料及作者论证，不将出现频次视为真理；争议区分定义、方法、证据或价值判断差异。
5. 作者展望与AI研究建议分开；作者声称空白也须注明为其主张及时间边界。
6. 原文含数学比较、元分析或量化综合时启用对应辅助模块，提取方法和局限，不因D分类屏蔽它们。

批判模式才展开覆盖偏差、选择性引用与综合方法的系统评估；明显材料缺失仍在普通报告中披露。
