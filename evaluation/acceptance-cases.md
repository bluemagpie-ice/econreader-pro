# 行为验收清单

状态：待在目标平台实际运行。本文件是测试输入与通过标准，不是通过报告。

共同硬失败：虚构事实、数字或定位；将未读附录声称已核实；相关性升级为因果；复制示范事实到新论文；伪造文件链接。每个关键事实须逐项回到原文核对，不以语言流畅代替准确性。

| 用例/输入 | 请求 | 可观察通过标准 |
|---|---|---|
| tests中的A论文全文 | 帮我读这篇 | 首答完整速读，A分布分析，不问卷阻塞，不套DID；结尾相关下钻 |
| B论文全文 | 精读模型 | 直接到模型层，解释激励约束，不强制FOC，不展开所有证明 |
| B论文指定命题 | 逐步解释该证明 | 分清原证明和补充解释；乱码/缺附录不猜测 |
| C论文全文 | 快速读懂 | 还原制度论证链及证据，短评价，不自动全面审稿 |
| D论文全文 | 梳理观点 | 主题和观点归属清楚；未读被引原文时注明转述 |
| E论文全文 | 解释主要贡献 | 方法辨析优先，公式不误认实际回归，建议注明条件 |
| 任一全文 | 我是初学者，要课堂汇报 | 利用背景调整术语解释，不再次问用途或基础 |
| 主文与其附录 | 读这篇论文 | 识别为一篇，不生成跨论文比较 |
| 两篇独立论文 | 帮我读这些 | 每篇简述、矩阵、关系分歧、下钻；关系区分实际继承与AI推断 |
| 两篇独立论文 | 只读第一篇 | 不强制比较 |
| 两篇不直接可比论文 | 比较结论 | 允许不可直接比较，不强判冲突或识别优劣 |
| 仅摘要 | 深度分析稳健性 | 标明无法核实，不说全文未报告，不补检验 |
| 无独立机制检验 | 分析机制 | 不把未做机制检验称为直接效应 |
| 任一论文 | 直接开始 | 对话内报告，不先问文件格式，不默认生成选题 |
| 已有报告 | 想要毕业论文选题 | 才展开研究建议，附数据、识别困难和条件性可行性 |
| 已有报告 | 导出Word | 按平台能力生成，或如实说明限制；不伪造链接 |
| 留出混合论文 | 速读 | 按主要贡献路由并启用辅助模块，不泄漏示范信息 |

速读和精读分别验收；保留实际输入和输出。出现硬失败应修正规则后重跑相关用例。目标平台验证和留出测试完成前，不宣称跨平台稳定或准确率。
